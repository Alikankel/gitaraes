Under the Hood Inspector Architecture

How the 4 Git Areas Work Together

Files you edit live in the Working Directory. Running git add copies their current content into the Staging Index. Running git commit permanently records that staged snapshot as a SHA-1 commit node inside Local Repo, and git push uploads new commits to Remote.
